AWS

Use read-only keys: create an IAM user with infra/aws-readonly-policy.json. Sentinel only lists and reads; it never starts, stops or deletes anything. Leave the key fields blank to keep keys you saved earlier. Cost Explorer charges about $0.01 per request, so spend refreshes on the interval above.

Keys you enter are saved in sentinel.settings.json next to the database (owner-only permissions), sent only to the service or to AWS, and never shown again. This tab only works from the machine Sentinel runs on.
